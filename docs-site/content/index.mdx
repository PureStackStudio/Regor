# Reactive UI without framework lock-in

Regor gives you direct DOM binding, precise reactivity primitives, and
TypeScript-native workflows for real applications.

<Flex wrap="true" class="my-6">
  <BtnLink href="/getting-started/" tone="accent">Start building</BtnLink>
  <BtnLink href="/guide/" tone="neutral">Read the guide</BtnLink>
  <BtnLink href="https://github.com/koculu/regor" tone="ghost">GitHub</BtnLink>
</Flex>

Regor is a modern reactive UI library for teams that want **power and control**.
Bind existing markup, build components in TypeScript, and adopt reactivity at
your own pace.

<Grid columns="1" columnsMd="2" class="gap-4 my-6">
  <FeatureCard title="Runtime-first" summary="Bind dynamic behavior directly on existing DOM, without a Virtual DOM dependency." />
  <FeatureCard title="Precise reactivity" summary="Model state with ref, sref, computed, watchEffect, observers, batch updates, and pause/resume controls." />
  <FeatureCard title="Powerful directives" summary="Lists, conditionals, events, text and HTML binding, forms, dynamic components, and attributes." />
  <FeatureCard title="Flexible components" summary="Build components in TypeScript with practical context behavior and dynamic composition." />
  <FeatureCard title="Choose your workflow" summary="Use npm packages, CDN ESM, or a global build, including build-less and CSP-friendly workflows." />
  <FeatureCard title="Performance by design" summary="Stay close to the DOM and optimize hot paths with full visibility." />
  <FeatureCard title="Progressive enhancement" summary="Adopt Regor incrementally in existing applications and static pages with dynamic islands." />
  <FeatureCard title="Library-friendly" summary="Integrate with external DOM logic and micro-frontend environments." />
</Grid>

This documentation is built with [PureStack](https://purestack.studio/), which
uses Regor for its components and browser behavior. Write Markdown for content
and use Regor MDX when a page needs components or interactivity.

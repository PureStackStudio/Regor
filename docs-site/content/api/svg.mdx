## Overview

Use `svg` to author an SVG component. Bind its attributes and text to reactive props, then use the component in an HTML template. Changes to the props update the existing SVG elements.

## Usage

```ts
import { createApp, html, ref } from 'regor'
import { defineBattery } from './battery-svg'

createApp(
  {
    charge: ref(65),
    charging: ref(false),
    components: { Battery: defineBattery() },
  },
  {
    selector: '#battery-app',
    template: html`
      <label>Charge
        <input type="range" min="0" max="100" r-model.number="charge" />
      </label>
      <Battery :charge="charge" :charging="charging" />
    `,
  },
)
```

The `battery-svg.ts` tab contains the complete SVG component. Mount this example into `<div id="battery-app"></div>`. The parent owns the state; `Battery` receives reactive props.

## Parameters

- `templates` (`TemplateStringsArray`): Static segments of the template literal.
- `...args` (`unknown[]`): Interpolated values inserted between template segments.

## Return Value

- Returns a `string` containing the combined SVG markup.

<AlertBox class="guide-callout" tone="accent" variant="surface" title="The same bindings work inside SVG"><p><code>:width</code> and <code>:fill</code> update the charge bar, text interpolation updates the percentage, and <code>r-if</code> adds or removes the charging bolt.</p></AlertBox>

## Notes

- `svg` behaves exactly like `html` at runtime (string assembly), so you can use it anywhere a template string is accepted.
- Use `svg` when you want semantic clarity in code and editor hinting for SVG snippets.
